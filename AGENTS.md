# AGENTS.md — Rüya Creative Ajans Portfolio

## Project Architecture

This is a **pure static site** — no build step, no framework. Three core files:

| File | Purpose |
|---|---|
| `index.html` | Full single-page app markup; all sections inline |
| `style.css` | All styles; CSS custom properties at `:root` for the palette |
| `main.js` | All interactivity; IIFE with 10 named modules |
| `netlify.toml` | Publish directory + security headers |

## Key Directories / Files

- `.netlify/state.json` — generated by Netlify Forms enable script; do not delete
- `netlify.toml` — `publish = "."` (root); no build command needed

## JavaScript Module Map (`main.js`)

1. **SmoothScroll class** — lerp scroll engine, desktop only, wraps `body` children in a `div.scroll-smoother-content` and drives `translateY`
2. **Custom Cursor** — `cursorDot` tracks mouse directly; `cursorRing` lags via lerp; expands on `[data-cursor="link"]`
3. **Camera Lens Canvas** — draws animated aperture blades, flare lines, particles on `#lensCanvas`; focus-in ease-out cubic over 2.2s
4. **Nav scroll state** — adds `.scrolled` class after 60px
5. **IntersectionObserver reveals** — `.reveal-line`, `.reveal-word`, `.reveal-fade`, `.split-line` → `.is-visible`
6. **Anchor smooth scroll** — integrates with SmoothScroll or falls back to native
7. **Service card 3D tilt** — `mousemove` perspective transform
8. **Contact form AJAX** — POSTs to `/` with `application/x-www-form-urlencoded`; shows `.form-success` on success
9. **Parallax** — hero content translateY + opacity fade on scroll
10. **ResizeObserver** — keeps smooth scroll body height in sync

## Coding Conventions

- No TypeScript, no bundler — browser-native ES5-compatible JS inside an IIFE
- CSS: BEM-flavored class names (`.service-card--wide`); all colours via `var(--*)` tokens
- Responsive breakpoints: 1024px (2-col services), 768px (mobile), 480px (cursor disabled)
- `data-cursor="link"` attribute on any interactive element expands the cursor ring

## Non-Obvious Decisions

- **SmoothScroll wraps body at runtime** — DOM nodes are moved inside `.scroll-smoother-content` in JS, not in HTML, to keep the HTML clean and SSR-friendly
- **Canvas hero is positioned absolute under z-index layers** — a `hero-overlay` radial gradient sits on top to prevent the canvas from washing out the text
- **Netlify Forms uses standard POST action `/`** — since this is a plain static site (not SSR), the default `/` endpoint works correctly; no `/__forms.html` skeleton needed
- **Service card opacity starts at 0 in CSS** — set via `.service-card { opacity: 0 }` in the stylesheet, then revealed by IntersectionObserver; this prevents FOUC
