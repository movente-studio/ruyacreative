# Rüya Creative Ajans — Cinematic Portfolio Website

A premium, ultra-modern agency portfolio website built for **Rüya Creative Ajans** around the concept of "Cinematic Digital Experience". The site feels like a movie intro — dark luxury aesthetics, scroll-driven animations, and immersive visual interactions.

## Key Technologies

- **Pure HTML5 / CSS3 / Vanilla JS** — zero framework dependencies, maximum performance
- **Netlify Forms** — serverless contact form with spam protection (honeypot)
- **Canvas API** — animated camera lens opening sequence in the hero
- **CSS Custom Properties & Grid/Flexbox** — responsive luxury layout system
- **Intersection Observer API** — scroll-triggered reveal animations
- **Custom Smooth Scroll Engine** — Lenis-style buttery-smooth lerp scrolling (desktop)

## Running Locally

```bash
# Requires Netlify CLI for Forms to work locally
npx netlify dev
# Site is served at http://localhost:8888
```

Without Netlify CLI, you can open `index.html` directly in a browser — all visuals and animations work; only form submission requires the Netlify environment.
